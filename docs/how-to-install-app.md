# Install Quizbun as an app

You can install Quizbun on your phone, tablet, or computer. It opens in its own window and helps protect the Quizzes and Progress stored on your device.

## iPhone or iPad using Safari

1. Open Quizbun in Safari.
2. Tap the Share button, which looks like a square with an upward arrow.
3. Scroll down and tap **Add to Home Screen**.
4. Tap **Add** in the top-right corner.

## Android using Chrome

1. Open Quizbun in Chrome.
2. Tap the three-dot menu in the top-right corner.
3. Tap **Add to Home screen** or **Install app**.
4. Follow the prompts to finish installing.

## Computer using Chrome or Edge

1. Open Quizbun in Chrome or Edge.
2. Open the browser menu and choose **Install Quizbun**. You may also see an install icon on the right side of the address bar.
3. Select **Install** when the browser asks you to confirm.
